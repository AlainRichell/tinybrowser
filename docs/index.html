Why

A whole browser is too much for one page.

You do not need a tab strip, a sidebar, a sync account and 600 MB of profile to keep an eye on a build, a dashboard or a chat. You need a window small enough to live in the corner and large enough to read.

tiny is that window. Type an address and it navigates there, with the same engine Edge uses. Every page is scaled so its whole width fits; you can resize it down to 60×60, pin it above everything, and hide every copy when you need the desktop back.

“Embedding an engine would mean tens of megabytes. WebView2 is already part of Windows, so the program itself is one 688 KB executable written in C++.”

That is the whole trick: the browser engine is already on your machine. tiny only adds the window, the gestures, the containers and the snapshots — and stays out of the way.

Features

Small window. Not a small browser.

Everything below is per window, not per app. Open as many as you need; they do not share a tab strip.

160×90, always on top

A real frameless window, not a panel. Pin it above every app, or let it behave like a normal window. Duplicate it with 4 px of air; never cover another copy.

688 KB, one .exe

Copy it anywhere and run it. No installer, no .NET, no VC++ redistributable, no Electron. The WebView2 runtime is already part of Windows.

one .exe · no installer · no .NET

Containers

A container is a separate profile for one window: cookies, sessions, storage, cache and history kept apart. Two Google accounts at once, or work and personal apart.

Snapshots: .to files

Freeze a window — address, position, size, zoom, container, corners, keyed colours — into a text file. Double-click it in Explorer and the window comes back exactly as it was.

Colour transparency

Ctrl+Alt+A arms an eyedropper. Everything painted in that colour disappears from that window and the desktop shows through — videos and animated GIFs included.

Rounded corners

A slider from 0 to 100 per window. At 0 it is the rectangle it always was; at 100 the corners meet and a 160×90 window becomes a capsule. Saved in the .to and copied on duplicate.

Ctrl+click a link

Opens it in another tiny window at the same size, in the next free spot, same container and corners. Plain clicks and target=_blank stay in the current window.

Gestures, not menus

Ctrl+Alt+S for the one-line strip, Ctrl+Alt+D to duplicate, Ctrl+Alt+C to hide every copy, Ctrl+Alt+T for a new window even with tiny closed, Alt+drag to move it.

No telemetry

No account, no cloud, no background service. The profile is a folder under %LOCALAPPDATA%\tinybrowser; the app is one exe and a .ini next to it.

Install

Ten seconds, no wizard.

  1. Download tinybrowser.exe — 688 KB.
  2. Double-click it. The window opens at the bottom-right corner, always on top.
  3. Type an address (or a search) and press Enter. No dots means a web search.
  4. Pin it, resize it, or keep it. The exe is the app; delete it and it is gone.

Needs Windows 10/11 x64 and the WebView2 runtime, which ships with Edge and Windows 11. The source and build.bat are in the repo.

The .exe is not code-signed. The first run shows SmartScreen’s “Windows protected your PC”. Choose More info → Run anyway. The whole source is public and the build is one batch file; if you prefer, compile it yourself.

FAQ

Before you ask.

Does it replace my browser?

No. It is the window you keep open next to your browser: one page, in the corner. A full browser with tabs is still the right tool for browsing.

Is it really one .exe?

Yes. The program is 688,640 bytes. It uses the WebView2 runtime that ships with Windows, so the engine is not inside the exe; that is why it can be this small.

Why does Windows warn me?

The exe is not code-signed, so SmartScreen shows its generic warning for a new unsigned binary. Choose More info → Run anyway, or build it yourself from the source.

Windows only?

Yes. It is built on Win32 and WebView2. There is no macOS or Linux build; the same idea exists elsewhere on those platforms, but this one is not a cross-platform app.

Where is my data?

In %LOCALAPPDATA%\tinybrowser. Containers are folders inside it. There is no account, cloud or telemetry. Deleting the exe and that folder removes everything.

Can I use two accounts at once?

Yes: give each window a different container. Cookies, sessions, storage and history stay apart, so two Google accounts can be open at the same time.
